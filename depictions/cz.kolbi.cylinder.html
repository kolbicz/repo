Cylinder Reborn

Make your icons dance

Animated page transitions for the Home Screen, written in Lua. Pick one or several effects, or write your own.

This fork combines upstream 1.2.0 with iPad rotation and icon-editing fixes, CFPreferences-based settings, logs kept inside the jailbreak root, and native roothide support.

It replaces com.ryannair05.cylinder: installing it removes the original package, and your settings and scripts carry over.

Based on Cylinder Reborn by Ryan Nair

1.2.0 2026-11-14

Combines upstream 1.2.0 with this fork's iPad, preferences, and native roothide fixes. Both packages require iOS/iPadOS 15 or later and contain arm64 and arm64e binaries.

Changes
  • Integrates upstream's rewritten animation engine, Lua 5.5.1, revised effects, and icon row/column/center APIs.
  • Preserves iPad rotation cleanup and suspends effects safely during icon editing and multi-icon dragging.
  • Retains CFPreferences-based settings and reliable PreferenceLoader staging.
  • Keeps diagnostic logs inside the jailbreak root and creates a mobile-owned log directory.
  • Preserves newer SpringBoard layout changes when restoring animated icons, incorporating the property-ownership fix from upstream's separate fix branch.
  • Fixes cleanup scheduling, inactive Lua handle access, Lua error handling, invalid numeric inputs, and formula selection/recovery UI issues.
Verification

Both package builds passed, along with cleanup regression tests and 2,790 host-side Lua effect scenarios. Package versions, settings entries, binary slices, and native roothide path strings were checked.

Physical-device testing is still needed for rotation, repeated multi-icon dragging, fly-in/app-return animations, and actual roothide preference redirection. Host-side tests do not verify SpringBoard rendering.

Source and detailed review: REVIEW-1.2.0.md.

1.1.5 2026-10-20

This release supports iOS 15 and newer and provides clearly labeled packages for both jailbreak environments:

  • com.ryannair05.cylinder_1.1.5_rootless_iphoneos-arm64.deb
  • com.ryannair05.cylinder_1.1.5_roothide_iphoneos-arm64e.deb
Changes
  • Merges applicable effect and Lua bridge optimizations from upstream commit 5fc3f5b (May 12, 2025).
  • Optimizes 14 bundled Lua effects.
  • Improves Lua view indexing, table handling, and transform processing.
  • Retains the iPad landscape, icon-drag recovery, preferences, rootless, and roothide fixes from this fork.
  • Keeps roothide preference access isolated from non-roothide mobile preference directories.

Both packages include the Cylinder settings bundle and PreferenceLoader entry. The tweak and preference binaries contain both arm64 and arm64e slices.

1.1.4 2026-09-09

Cylinder Reborn 1.1.4 for iOS 15 and later.

Changes since 1.1.3:

  • Fixes Cylinder effects disappearing after moving multiple icons between Home Screen pages.
  • Suspends page effects while icons are being rearranged and resumes them afterward.
  • Makes Lua effect removal and fallback handling safe.
  • Uses CFPreferences for reliable shared preferences between Settings and SpringBoard.
  • Keeps tweak-owned logs and error state inside the active rootless or roothide jailbreak root.
  • Contains no direct /var/mobile, /private/var, or preference-plist paths in the roothide binaries.

Downloads:

  • com.ryannair05.cylinder_1.1.4_rootless_iphoneos-arm64.deb — rootless jailbreaks.
  • com.ryannair05.cylinder_1.1.4_roothide_iphoneos-arm64e.deb — roothide jailbreaks.

1.1.3 2026-08-22

Cylinder Reborn 1.1.3 for iOS 15 and later.

Changes:

  • Fixes icons becoming stuck, partially transparent, or misplaced during landscape transitions on iPad.
  • Fixes Cylinder effects disappearing after moving multiple icons between Home Screen pages.
  • Suspends page effects while Home Screen icons are being edited, then resumes them normally afterward.
  • Makes Lua effect failure handling safe when an effect is removed at runtime.
  • Uses CFPreferences for shared Settings/SpringBoard preferences, matching SBTweaker.
  • Moves logs and error state into the active rootless or roothide jailbreak root; no direct mobile-preferences or mobile-log paths are used.
  • Includes clearly named rootless and roothide packages.

Choose the package containing rootless or roothide in its filename to match your jailbreak environment.
